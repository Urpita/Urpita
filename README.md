## 🌠 Featured: Starry Flow

> *What if a photo could swirl like Van Gogh's sky?*

Scientists found that the swirls in *The Starry Night* follow the same patterns as real fluid turbulence. **Starry Flow** turns any photo into a living, moving painting: edges become a flow field (rotated 90° so the flow circles around shapes), curl noise adds natural turbulence, and thousands of brushstrokes carry the photo's colors along it.

| | |
|---|---|
| 🎨 **Idea** | Painting + code, just for fun |
| 🧰 **Stack** | Canvas / JavaScript, then Python · PyTorch (AdaIN style transfer) · FastAPI · Next.js |
| 📈 **Status** | Browser prototype done, style transfer backend in progress |
